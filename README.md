# Screenshot

Windows screenshot utility with a configurable global shortcut, selection capture, annotations, clipboard copy, desktop pinning, tray residency, and startup configuration.

## Download

The runnable `ScreenshotTool.exe` is available from the repository's **Releases** page. It is a self-contained Windows executable and does not require a separately installed .NET runtime.

## Source

Open `ScreenshotTool/ScreenshotTool.csproj` with Visual Studio, then build for Windows x64. You can also run `build.ps1` to generate the self-contained executable locally.
